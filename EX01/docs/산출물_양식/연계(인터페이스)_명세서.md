|:--|:--|:--|:--|:--|:--:|
| id     | number | id        | Long    | 그대로 | Y |
| userId | number | userId    | Long    | 그대로 | Y |
| title  | string | title     | String  | trim   | Y |
| body   | string | body      | String  | trim   | N |
| (없음) | -      | createAt  | LocalDateTime | 수신 시각 now() | N |
