# 가이드 — 구현 참고 사항

| 참고가 필요한 부분 | 관련 학습 모듈 |
|:--|:--|
| RestTemplate / UriComponentsBuilder / getForObject·exchange | 12_RESTFUL_API |
| 우리 REST API 재제공(@RestController/ResponseEntity) | 11_RESTCONTROLLER |
| Entity/JpaRepository/@Transactional | 07_JPA, 09_TX |
| @EnableScheduling / @Scheduled(cron·fixedRate) | 16_SCHEDULED |
| SecurityFilterChain / formLogin·httpBasic / hasRole / BCrypt | 19_SECURITY |
| @RestControllerAdvice / 커스텀 예외 @ResponseStatus | 05_EXCEPTION |

## 구현 힌트
- 외부 호출: `new RestTemplate().exchange(url, HttpMethod.GET, null, PostDTO[].class)` →
  `res.getStatusCode()` 가 `HttpStatus.OK` 아니면 `throw new MyBizException(...)`.
- URL 조립: `UriComponentsBuilder.fromHttpUrl("https://jsonplaceholder.typicode.com/posts").toUriString()`.
- 저장: 응답 `PostDTO[]` 를 돌며 `postRepository.save(dto.toEntity())`, `syncPosts()` 에 `@Transactional`.
- 배치: `LinkScheduler` 에 `@Scheduled(fixedDelayString="${link.sync.delay:60000}")` → `linkService.syncPosts()` 호출 + 로그.
- 보안: `SecurityFilterChain` 에서 `authorizeHttpRequests(a -> a.requestMatchers(HttpMethod.POST,"/api/link/sync").hasRole("ADMIN").anyRequest().authenticated())` + `httpBasic(Customizer.withDefaults())`.
  사용자: `InMemoryUserDetailsManager(user/ADMIN 없음, admin/ADMIN)`, `BCryptPasswordEncoder`.
- 테스트: `@SpringBootTest` 에서 `linkService.syncPosts()` 호출 후 저장 건수 > 0 확인(외부망 필요).

## 공공데이터 API 로 교체하는 법 (옵션)
기본 외부 API(jsonplaceholder) 대신 **공공데이터포털 OpenAPI**(예: 기상청 단기예보)로 바꿔 풀 수 있습니다.
1. `application.properties` 의 `link.api.base` 를 공공데이터 서비스 URL 로 변경합니다.
2. 발급받은 **serviceKey** 를 `application-dev.properties` 에 두고(`link.api.serviceKey`), 코드에서 `@Value` 로 주입합니다 — 인증키는 Git 에 올리지 않습니다(보안 NCS 2-3).
3. `LinkServiceImpl.syncPosts()` 의 `UriComponentsBuilder` 에 `.queryParam("serviceKey", key)` 등 필수 파라미터를 추가합니다.
4. 외부 응답 형식이 **XML 이면** Jackson XML 또는 응답 타입을 그에 맞게 매핑합니다.
5. `PostDTO` 필드와 `tbl_post` 스키마, **연계(인터페이스) 정의서·명세서**를 해당 공공데이터 항목에 맞게 수정합니다.
> 핵심 구조(Controller→Service→Repository, @Scheduled, Security, 예외처리)는 그대로 두고, **연계 대상·DTO·명세서만** 교체하면 됩니다.
