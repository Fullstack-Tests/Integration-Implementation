# 작업지시서 — 통합 구현 (외부 OpenAPI 연계 / S-Link)

> 능력단위: 통합 구현 (NCS 2001020206) / 6수준
> 분류: 모듈시험(조별) · 예상 3시간 · 합격선 60점

---

## ① 작업지시서(문제)
미완성 EX01(S-Link) 프로젝트의 핵심 클래스 TODO(PostDTO, PostRepository, LinkServiceImpl,
LinkController, LinkScheduler, SecurityConfig, 테스트)를 진도(12_RESTFUL_API · 11 · 16_SCHEDULED ·
19_SECURITY · 05) 패턴으로 구현하여, 외부 OpenAPI 연계(수신) → 표준 DTO 변환 → DB 저장 →
우리 REST API 재제공 → @Scheduled 배치 동기화가 정상 동작하고, 연계 오류 처리와 접근 보안이
적용되도록 완성하고 동작 화면(Postman)을 제출하시오. (DB 스키마 + 일부 골격 제공)

## ② 내용(설명)
```
[확인]
- 연계 대상  : 외부 OpenAPI https://jsonplaceholder.typicode.com (인증 불필요, 기본)
               ※ 공공데이터포털 OpenAPI(예: 기상청 단기예보 등)로 교체할 수 있습니다. base URL·serviceKey 는
                 application(-dev).properties 로 설정하고(인증키는 보안상 분리합니다), PostDTO 필드와
                 연계(인터페이스) 정의서·명세서는 해당 공공데이터 응답에 맞게 수정합니다.
- 연계 데이터: 게시글 Post {userId, id, title, body}  →  표준 PostDTO / Post(Entity)
- 흐름       : 외부 API(수신) → 변환 → DB 저장 → 우리 REST API 재제공 / @Scheduled 주기 동기화
- 연계 메커니즘: RestTemplate + UriComponentsBuilder (GET)
- 오류 처리  : 호출 실패·비정상 상태코드·null → MyBizException → @RestControllerAdvice
- 보안       : SecurityFilterChain — /api/link/sync(ADMIN), /api/link/posts(인증), httpBasic
- 배치       : @EnableScheduling + @Scheduled (주기 동기화)
- DB 연동    : Spring Data JPA(JpaRepository) → MySQL testdb
- 환경       : JDK 21 / Spring Boot 3.5.x / MySQL 8.x / 내장 Tomcat 8090
- 제공물     : db/schema.sql, DemoApplication(@EnableScheduling), Post(Entity),
               LinkService(인터페이스), GlobalExceptionHandler, MyBizException
               · PostDTO 속성·검증 제공(변환 메서드는 학생 구현)
- 학생 구현  :
   · PostDTO(toEntity) · PostRepository(선언) · LinkServiceImpl(syncPosts/getPosts/getPost)
   · LinkController(sync/posts/post) · LinkScheduler(@Scheduled) · SecurityConfig(FilterChain) · 테스트

[핵심 구현 요구사항]
1) PostDTO         : 속성·검증 제공 / toEntity() 로 Post 변환 (static from(Post) 포함)
2) PostRepository  : extends JpaRepository<Post, Long>  (필요 시 existsById 등 활용)
3) LinkServiceImpl :
   - syncPosts() : @Transactional. RestTemplate+UriComponentsBuilder 로 외부 /posts 호출,
                   상태코드 OK 아니면 MyBizException, 응답을 PostDTO[]→Post 로 저장, 저장 건수 반환
   - getPosts()/getPost(id) : @Transactional(readOnly=true), DB 조회 → DTO 반환
4) LinkController  (@RestController, /api/link) :
   - POST /sync      : syncPosts() 호출 → 건수+메시지 (ADMIN 권한)
   - GET  /posts     : getPosts() → 목록
   - GET  /posts/{id}: getPost(id) → 단건
5) LinkScheduler   : @Scheduled(주기) 로 LinkService.syncPosts() 자동 호출 + 로그
6) SecurityConfig  : SecurityFilterChain — /api/link/sync=ADMIN, /api/link/**=인증, httpBasic,
                     BCryptPasswordEncoder + InMemoryUserDetailsManager(user/admin)
7) 테스트          : 동기화 정상(저장 건수>0) / 외부 호출 실패 시 MyBizException
```
